# starter-kit

Your first Java program. In the Starter kit session you run it in IntelliJ IDEA (as `Hello.java`). This copy lets you also try it from the terminal, to see that JDK 21 works on its own.

## Run it from the terminal

Use JDK 21. Open a terminal in this folder and type:

```sh
java Hello.java
```

Java 21 compiles and runs a single file in one step.

## Run it the long way (compile, then run)

```sh
javac Hello.java
java Main
```

`javac` makes `Main.class` (bytecode), and `java Main` asks the JVM to run it.

## Expected output

```text
Hello, backend!
```
